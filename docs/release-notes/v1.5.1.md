## mind v1.5.1

Patch release with a fix for the Neural Map graph view in the web UI.

### Highlights

- **Neural Map rendering fixed** — graph nodes now position correctly around
  their tier rings instead of clustering at the upper-left corner of the canvas.

### Fixed

- Nodes on the Neural Map collapsed to the upper-left origin when a space
  used UUID memory identifiers (default since v1.5.0 schema migration).
  The layout engine assumed numeric IDs and produced `NaN` coordinates;
  it now uses deterministic string-aware sorting and hashing so nodes
  render at the correct tier-ring positions regardless of ID format.
