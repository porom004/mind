## mind v1.5.0

This release makes mind easier to keep in sync, safer to update, and more
reliable for agent workflows.

### Highlights

- Added autosync commands to mirror spaces into versioned `.mind/` files.
- Added safer database migrations with automatic backups and restore on failure.
- Added `mind setup refresh` so existing agent integrations stay up to date.
- Moved session summaries into the project space and added a migration command
  for older summaries.
- Fixed the public installer launcher path so new installs run the correct entry
  point.
- Improved `mind update` so it validates migrations before refreshing
  integrations.

### Upgrade notes

Run `mind update`, then run `mind setup` to refresh your agent integration. If
you have older session summaries under `sessions/<repo>`, run
`mind migrate sessions projects/<repo> --dry-run`, then run
`mind migrate sessions projects/<repo>`.
